Task Details

The task involves identifying XYZ patterns in multilingual texts. Participants are expected to build systems capable of handling diverse linguistic features. The sub-tasks include:

  • Subtask 1: Classification of ABC
  • Subtask 2: Extraction of DEF

Example Datasets

Sample datasets will be provided in JSON and CSV formats. Below are a few examples:

{
  "id": "001",
  "text": "The quick brown fox jumps over the lazy dog.",
  "label": "Positive"
}

More examples and full data will be available on the GitHub repository.

Evaluation

Systems will be evaluated using the following metrics:

  • Accuracy
  • F1-Score (macro & micro)
  • Precision and Recall

A leaderboard will be maintained throughout the competition.
